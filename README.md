# grandma_tools

Collection of independent scripts and tools to automate GRANDMA workflows.

## Available tools

* OwnCloud service : An automatic monitoring service for new SkyPortal sources that creates structured folders on ownCloud.
* SkyPortal processor service : An automatic monitoring service for SkyPortal comments that runs StdWeb forced photometry on new files from OwnCloud and uploads the result back to SkyPortal as photometry.
